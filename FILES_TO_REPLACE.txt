FILES TO REPLACE - everything from 13/08/2026 to now
====================================================

44 files in total: 7 brand new, 37 replaced.
All paths are inside your site folder (the one holding index.php).

Please put ALL of them up together. They depend on each other - for example
the bill numbers come from a new helper file that only loads because
config/autoload.php was changed, so replacing one without the other leaves
the system half working.

DO NOT touch application/config/database.php. It holds your database login
and is different on every server.

If it is easier, copy the whole sub.asrenish.com folder from the GitHub zip
over your live folder - that does exactly the same thing. Just keep your own
application/config/database.php.


NEW FILES - upload these (they do not exist on your server yet)
---------------------------------------------------------------
 1. migrate.php
      The browser update tool. Sits next to index.php.
      Set the password inside it, run the steps, then delete it.

 2. application/helpers/billno_helper.php
      Builds the bill number HG-B-001 from the branch name, and reads a
      typed-in bill number back to the right sale.

 3. application/helpers/access_helper.php
      The page permission check used by the pages below.

 4. application/migrations/v9_billno_storecredit_privileges.sql
      Database: adds the new columns and tables. Step 2 in migrate.php.

 5. application/migrations/v10_data_repair.sql
      Database: repairs the records saved wrong. Step 3 in migrate.php.

 6. application/migrations/v11_exchange_discount.sql
      Database: the discount columns for exchanges. Step 4 in migrate.php.

 7. application/migrations/v12_expense_subcategories.sql
      Database: the parent-category column for expenses. Step 5 in migrate.php.

ORDER OF WORK
-------------
1. Back up the database (phpMyAdmin > Export > Go) and the site folder.
2. Upload all the files above, replacing when asked.
3. Open https://your-site/migrate.php, set the password inside the file
   first, then run steps 2, 3, 4 and 5.
4. Delete migrate.php with the button on that page.
