FILES TO REPLACE - everything from 13/08/2026 to now
====================================================

33 files in total: 5 brand new, 28 replaced.
All paths are inside your site folder (the one holding index.php).

Please put ALL of them up together. They depend on each other - for example
the bill numbers come from a new helper file that only loads because
config/autoload.php was changed, so replacing one without the other leaves
the system half working.

DO NOT touch application/config/database.php. It holds your database login
and is different on every server.


NEW FILES - upload these (they do not exist on your server yet)
---------------------------------------------------------------
 1. migrate.php
      The browser update tool. Sits next to index.php.
      Set the password inside it, run the two steps, then delete it.

 2. application/helpers/billno_helper.php
      Builds the bill number HG-B-001 from the branch name, and reads a
      typed-in bill number back to the right sale.

 3. application/helpers/access_helper.php
      The page permission check used by the pages below.

 4. application/migrations/v9_billno_storecredit_privileges.sql
      Database: adds the new columns and tables. Step 2 in migrate.php.

 5. application/migrations/v10_data_repair.sql
      Database: repairs the records saved wrong. Step 3 in migrate.php.

 6. (repo root) HOW_TO_UPDATE.txt
      Written instructions only. Nothing to upload - read it and keep it.


REPLACE - settings
------------------
 7. index.php
      Switches error display OFF. This is what stopped the PHP error
      printing on a customer's bill.

 8. application/config/autoload.php
      Loads the two new helper files above. Without this file the bill
      numbers and the permissions will not work at all.


REPLACE - controllers  (application/controllers/)
-------------------------------------------------
 9. Sales.php
      Gives every new bill its branch number, passes the sold and redeemed
      gift vouchers to the printed bill, removes an empty bill if no line
      could be saved.

10. Returns.php
      Cash returned / store credit choice, records how the refund money
      moved, files the return against the right branch.

11. Reports.php
      Cash Flow: the payment method filter now applies to the totals at the
      top, not only to the table.

12. Userauthentication.php
      Saves the new permission tick boxes when you create or edit a user.

13. CustomerPayment.php
      Accepts the new bill number (HG-B-001) as well as the old AS00 one
      when you look a bill up.

14. DeliveryCompany.php
15. StoreItems.php
16. RetailPosController.php
      These three now check the user's permission before opening, which is
      what makes the tick boxes in user creation actually take effect.


REPLACE - models  (application/models/)
---------------------------------------
17. Report_model.php
      The cash flow engine. This is the change-given fix: a 4,900 bill paid
      with 5,000 now shows 5,000 in and 100 out.

18. Sales_model.php

      same moment, reads the bill lines from the sale itself, lists the
      vouchers on a bill.

19. Returns_model.php

20. Payment_model.php
      Shows the printed bill number on the customer payment screen.

21. User_model.php
      The new permission columns.

22. Stocks_model.php
      Fixes the stock list when "All items" is selected.


REPLACE - screens  (application/views/)
---------------------------------------
23. transactions/addsale.php
      The save button is disabled the moment it is pressed, so a double

25. returns/return_invoice.php

26. returns/list_returns.php
      Shows the new bill number in the list.

27. invoice/invoice.php
      Inv No. and Bill By right aligned, gift vouchers printed as their own
      lines with the card number, new bill number, no empty Address line.

28. customer/addcustomer.php
      Address, balance and credit limit hidden and no longer required.

29. auth/register.php
      Every page now appears as a tick box when creating a user.

30. templates/header.php
      The menu only shows what the user is allowed to open.

31. report/today-summary.php
      New "Change Given" line so the till balance tallies.

32. listing/allproductionsales.php
      A tailoring payment can no longer be more than the amount still due.

33. payment/Payment-Customer.php
      Shows the new bill number instead of AS00.

34. listing/show-stock-list.php
      The stock list was loading empty and had no search or export. Fixed.


ORDER OF WORK
-------------
1. Back up the database (phpMyAdmin > Export > Go) and the site folder.
2. Upload all the files above, replacing when asked.
3. Open https://your-site/migrate.php, set the password inside the file
   first, then run step 2 and step 3.
4. Delete migrate.php with the button on that page.

If it is easier for you, copying the whole sub.asrenish.com folder from the
GitHub zip over your live folder does exactly the same thing - just keep
your own application/config/database.php.
